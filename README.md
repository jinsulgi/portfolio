# Portfolio

Site vitrine de mes projets en science des données, en HTML/CSS simple (aucune dépendance).

## Contenu

- `index.html` : la page (à propos, projets, compétences, contact)
- `style.css` : la mise en forme, avec thème sombre automatique

## Voir le site en ligne avec GitHub Pages

1. Dans le dépôt : **Settings → Pages**
2. **Source** : *Deploy from a branch*
3. Choisir la branche par défaut et le dossier `/ (root)`, puis **Save**

Le site sera disponible quelques minutes plus tard à l'adresse
`https://jinsulgi.github.io/portfolio/`.

## Modifier le contenu

Les passages marqués `<!-- À compléter -->` ou `<!-- À personnaliser -->` dans
`index.html` sont à remplir avant de partager le site.
